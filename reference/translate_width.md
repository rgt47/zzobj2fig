# Translate a LaTeX width spec to a Typst width

Translate a LaTeX width spec to a Typst width

## Usage

``` r
translate_width(width)
```

## Arguments

- width:

  Character. A LaTeX-style width such as `"\textwidth"`,
  `"0.8\textwidth"`, or a plain Typst width like `"80%"` or `"5cm"`.

## Value

Character. A Typst width expression.
